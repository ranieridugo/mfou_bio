Supporting material to the paper:

Neural integrator and orchestrator communities shape spontaneous signaling in the human brain \n
Lorenzo Pini, Ranieri Dugo, Paolo Pigato, Maurizio Corbetta \n
bioRxiv 2026.02.04.703687; doi: https://doi.org/10.64898/2026.02.04.703687

The scripts contain the original code used in the statistical analysis. 
- d_* stands for data;
- f_* stands for function;
- c_* stands for computation;
- p_* stands for program.

The analysis pipeline involves importing data and calling functions within the computation scripts to calculate the quantities of interest and analyze them using both imported functions and general-purpose code in the program scripts. \n
Note that the data folders contain only a few cases from the Human Connectome Project due to storage limitations on GitHub. \n
The code cannot be run directly and requires adjustments, particularly with respect to directory paths, before execution.
